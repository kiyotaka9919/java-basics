This repository grows as I learn. Topics include (or will include):

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- Any editor or IDE (IntelliJ IDEA, VS Code, Eclipse)

Check your installation:

```bash
java -version
javac -version
```

### Running a Problem

```bash
# Compile
javac path/to/ProblemName.java

# Run
java -cp path/to ProblemName
```

If a file declares a `package`, compile and run from the project root using the full package name instead.
